One sentence that explains the modern internet to a traveler from 1800,
using only images they would know — roads, the post office, the library,
the market square — with a surprise at the end.

## Run

```sh
node main.ts
```

Writes the sentence to `output/entry.txt` (193 characters, UTF-8, one sentence).
